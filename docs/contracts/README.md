# docs/contracts — Внешние контракты данных

Папка `contracts/` описывает **внешние контракты данных** admin-панели «Слово.Проповеди»: то, что находится за пределами этого репозитория и с чем он обменивается данными.

- **REST API** — общий для платформы контракт: спецификация OpenAPI v0.2.0 «Admin API — Слово.Проповеди» живёт во внешнем swagger-репозитории, а отсюда кодогенерируется в обе стороны (Orval → backend, @hey-api → frontend). Документируется здесь: [`rest-api.md`](./rest-api.md).

От «схем» (например, `frontend/features/`) контракты отличаются тем, что описывают **протоколы и форматы данных**, а не бизнес-логику.

## Правила

1. **При изменении API обновляй этот файл в том же PR.**
   Изменение кода (эндпоинт, тип ответа, поле сущности) или регенерация клиента без обновления `contracts/` считается неполным.

2. **Все эндпоинты / типы — точный источник истины; код обязан им соответствовать.**
   Если агент обнаруживает расхождение между кодом и `contracts/`, он должен привести код в соответствие с контрактом **или** (если код намеренно изменился) обновить контракт — и в любом случае зафиксировать разницу.

3. **Не выдумывай факты.** Если данные неизвестны, проверь через `read`/`grep` в коде либо пометь `<!-- TODO -->`. Сомнительные места помечай в [`../debt.md`](../debt.md).

4. **Спецификация — внешняя.** Сам файл `openAPI.yaml` в этом репозитории отсутствует; единственная локальная копия — сгенерированные файлы. Кодогенерация зависит от доступности удалённого URL `https://docs.slovo-propovedi.ru/openAPI.yaml` (см. `debt.md`).
